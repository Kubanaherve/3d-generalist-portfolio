GLB Asset Validator & Batch Exporter (Blender bpy Add-on)

Developed an automated quality-assurance add-on for Blender 4.0+ built with bpy, bmesh, and mathutils. The tool detects non-manifold edges, N-gons, unapplied transforms, and missing UV sets before performing automated batch glTF/GLB exports.

  • Audits transforms: catches unapplied rotation and non-uniform scaling
  • BMesh topology pass: isolates zero-area faces and non-manifold boundaries
  • Interactive N-panel UI with direct 1-click viewport element isolation
  • Production batch export operator with coordinate conversion and LOD structuring

# Validating topology hygiene via bmesh
bm = bmesh.new()
bm.from_mesh(obj.data)
bm.edges.ensure_lookup_table()
bm.faces.ensure_lookup_table()

non_manifold = [e for e in bm.edges if not e.is_manifold]
if non_manifold:
    item = scene.validator_issues.add()
    item.obj_name = obj.name
    item.issue = f"Non-Manifold Edges ({len(non_manifold)})"

ngons = [f for f in bm.faces if len(f.verts) > 4]
if ngons:
    item = scene.validator_issues.add()
    item.obj_name = obj.name
    item.issue = f"N-gons Detected ({len(ngons)})"

bm.free()
